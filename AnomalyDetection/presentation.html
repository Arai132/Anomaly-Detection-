03 The Detectors

All detectors extend BaseDetector and share an identical interface.

Tree-based

IsolationForestDetector

Isolates anomalies by randomly partitioning features. Points that require fewer splits to isolate get higher anomaly scores. Wraps sklearn's IsolationForest; sklearn's −1/+1 output is converted to 1/0.

Density

LOFDetector

Local Outlier Factor compares the local density of a point to its neighbours. Uses novelty=True so it can score new data after training. Score = negative LOF score (flipped sign).

Statistical

ZScoreDetector

Flags any sample whose maximum feature-wise z-score exceeds a threshold (default 3.0). Learns per-feature mean and std at fit time. Zero-std features are protected from division by zero.

Statistical

IQRDetector

Flags samples outside [Q1 − k·IQR, Q3 + k·IQR] on any feature (default k = 1.5). Score is the normalised IQR-distance from the nearest fence, so it works with score_samples() too.

Deep Learning

AutoencoderDetector

MLP with a bottleneck hidden layer (sklearn MLPRegressor) trained to reconstruct its own input. Anomaly score = mean squared reconstruction error. Points the model cannot reconstruct well are anomalies.

Probabilistic

GaussianDetector

Fits a Gaussian Mixture Model (default: 1 component = single Gaussian). Anomaly score = negative log-likelihood, so low-probability regions score high. Uses sklearn's GaussianMixture.

BaseDetector interface

src/detectors/base.py
class BaseDetector(ABC):

04 Ensemble Stacking

Inspired by Chuying Ma's ODSC West 2023 talk, EnsembleStackingDetector combines scores from heterogeneous detectors to produce a single unified anomaly score that is more robust than any individual detector alone.

Unsupervised mode

No labels provided

Each detector's scores are min-max normalized to [0,1], then averaged. The threshold for flagging anomalies is set at the threshold_percentile of the training unified scores.

Semi-supervised mode

Sparse labels provided (y ≠ −1)

A LogisticRegression meta-learner is trained on the stacked score matrix using only the labeled rows. Its predicted probability of anomaly becomes the unified score. Class weights are balanced to handle the minority-anomaly problem.

ensemble_stacking.py — key logic
# Build the ensemble
ensemble = EnsembleStackingDetector(
    detectors=[AutoencoderDetector(), GaussianDetector(), IsolationForestDetector()],
    threshold_percentile=95,
)

# Unsupervised: just pass X
ensemble.fit(X_train)

# Semi-supervised: pass sparse labels (-1 = unlabeled)
ensemble.fit(X_train, y=y_sparse)   # trains LogReg meta-learner on labeled rows

scores = ensemble.score_samples(X_test)  # unified anomaly score
preds  = ensemble.predict(X_test)         # 0 or 1

05 Semi-Supervised Label Augmentation

In real-world fraud/anomaly scenarios you may have thousands of transactions but only a handful of confirmed fraud labels. SemiSupervisedAugmenter iteratively grows the label set using the ensemble's own predictions as pseudo-labels.

1

Start with sparse labels

make_sparse_labels(y_true, label_fraction=0.1) keeps 10 % of each class labeled; the rest become −1 (unlabeled).

2

Fit ensemble on labeled subset

The ensemble is fit using only rows where y ≠ −1. When both classes are present, the logistic meta-learner is trained.

3

Score all unlabeled points

The fitted ensemble assigns a unified anomaly score to every unlabeled sample.

4

Assign pseudo-labels

Scores above the anomaly_percentile → label 1. Scores below normal_percentile → label 0. Ambiguous points stay −1.

5

Repeat up to max_iters

Each iteration the labeled set grows, improving the meta-learner's signal. The loop stops early if no new labels are assigned.

semi_supervised.py
from src.utils.semi_supervised import make_sparse_labels, SemiSupervisedAugmenter

# Simulate scarce labeling (only 10% of each class labeled)
y_sparse = make_sparse_labels(y_train, label_fraction=0.1)
# y_sparse: array of  -1 (unlabeled) | 0 (normal) | 1 (anomaly)

augmenter = SemiSupervisedAugmenter(
    detector=ensemble,
    anomaly_percentile=90,   # top 10% of unlabeled scores → anomaly
    normal_percentile=20,    # bottom 20% of unlabeled scores → normal
    max_iters=3,
)
y_augmented = augmenter.fit_augment(X_train_arr, y_sparse)
# y_augmented: same shape, more 0s and 1s, fewer -1s

06 How to Use It

Install dependencies

terminal
pip install -r requirements.txt

Run the full benchmark

terminal
python main.py

This will: generate 2 000 synthetic samples (5 % anomalies), train all detectors, print a comparison table, save plots to reports/, then run the semi-supervised ensemble section.

Run tests

terminal
pytest tests/test_detectors.py -v

Use a single detector in your own code

Python
from src.detectors import IsolationForestDetector
from src.utils.data_loader import load_csv, preprocess

X, y = load_csv("data/raw/my_data.csv", target_col="label")
X_train_s, X_test_s, scaler = preprocess(X_train, X_test)

det = IsolationForestDetector(n_estimators=200, contamination=0.03)
det.fit(X_train_s)
preds = det.predict(X_test_s)   # 1 = anomaly, 0 = normal
scores = det.score_samples(X_test_s)

det.save("models/iforest.pkl")   # persist for later

07 config.yaml Reference

All hyperparameters live in config.yaml — no hard-coded values in the source files.

config.yaml
data:
  raw_path: data/raw          # where to look for CSV files
  processed_path: data/processed
  test_size: 0.2             # 80/20 train-test split
  random_state: 42

detectors:
  isolation_forest:
    n_estimators: 100         # number of trees
    contamination: 0.05       # expected fraction of anomalies
    random_state: 42
  lof:
    n_neighbors: 20
    contamination: 0.05
  zscore:
    threshold: 3.0            # σ beyond which a point is flagged
  iqr:
    multiplier: 1.5           # k in [Q1 − k·IQR, Q3 + k·IQR]
  autoencoder:
    encoding_dim: 16          # bottleneck layer size
    epochs: 50
    batch_size: 32
    threshold_percentile: 95  # percentile of train scores used as anomaly cutoff
  gaussian:
    n_components: 1           # number of Gaussians in GMM
    covariance_type: full
    threshold_percentile: 95
  ensemble_stacking:
    threshold_percentile: 95

semi_supervised:
  label_fraction: 0.1        # fraction of each class initially labeled
  anomaly_percentile: 90     # unlabeled scores above this → pseudo-anomaly
  normal_percentile: 20      # unlabeled scores below this → pseudo-normal
  max_iters: 3               # max pseudo-labeling rounds

evaluation:
  metrics: [precision, recall, f1, roc_auc]
  plots: true

models:
  save_path: models/

08 Adding a New Detector

The plugin system is three steps.

1

Create src/detectors/my_detector.py

my_detector.py
from .base import BaseDetector

class MyDetector(BaseDetector):
    def fit(self, X, y=None):
        arr = self._to_array(X)
        # ... train your model ...
        self.is_fitted = True
        return self

    def predict(self, X):
        return (self.score_samples(X) > self._threshold).astype(int)

    def score_samples(self, X):
        # return higher score for more anomalous points
        ...
2

Export it from src/detectors/__init__.py

__init__.py
from .my_detector import MyDetector
__all__ = [..., "MyDetector"]
3

Add its hyperparameters to config.yaml and wire it into main.py

Drop it into the detectors dict in main() and it will automatically be benchmarked, evaluated, and plotted alongside the existing detectors.

To include it in the ensemble, pass it to EnsembleStackingDetector(detectors=[...]). The only requirement is that it implements score_samples().

Tip — training on normal data only: For the Autoencoder and Gaussian detectors, if you have confirmed normal samples you can pass X_normal to fit() rather than the full mixed dataset. The reconstruction error / log-likelihood will be sharper at flagging deviations.
Tip — real-time scoring: Call detector.save("models/my.pkl") after training, then BaseDetector.load("models/my.pkl") in a serving process. score_samples() works on single rows — just pass a shape [1, n_features] array.
